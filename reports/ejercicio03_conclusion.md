# Conclusión integrada · Ejercicio 03

El desarrollo de LAB04 y LAB05 permitió construir una ruta reproducible de procesamiento de lenguaje natural desde la selección y auditoría de un corpus público hasta el entrenamiento, evaluación e interpretación de clasificadores de texto. El dataset seleccionado fue *Inflation Research Abstracts Classification*, obtenido del UCI Machine Learning Repository. El corpus contiene 1,138 abstracts académicos en inglés relacionados con inflación y una variable objetivo binaria, `Label`, utilizada para distinguir investigaciones asociadas o no con metodologías de machine learning o inteligencia artificial. La selección se sustentó en su procedencia pública, licencia identificable, actualidad, variable objetivo original y adecuación a una tarea de clasificación textual.

La auditoría permitió detectar aspectos relevantes antes del modelado. No se encontraron valores nulos en las variables `Abstract` y `Label`, pero sí 13 abstracts duplicados. Además, se observó desbalance entre las clases: aproximadamente 79.09 % de los registros pertenecen a la clase `0` y 20.91 % a la clase `1`. Este resultado justificó evitar el uso aislado de accuracy y prestar mayor atención a métricas por clase y F1 macro. Los duplicados fueron eliminados antes de dividir los datos, con el propósito de reducir el riesgo de fuga de información entre entrenamiento y prueba.

En LAB05 se entrenaron tres pipelines comparables utilizando TF-IDF dentro de cada pipeline: DummyClassifier como baseline, Complement Naive Bayes y regresión logística. Los resultados mostraron una diferencia importante entre los modelos. El baseline obtuvo un F1 macro de 0.442 y no logró recuperar ningún caso de la clase minoritaria. Complement Naive Bayes alcanzó un F1 macro de 0.459, con recall de apenas 0.02 para la clase `1`. La regresión logística obtuvo el mejor desempeño, con F1 macro de 0.837 y accuracy de 0.89. Para la clase `1` alcanzó precision de 0.75, recall de 0.73 y F1 de 0.74.

La matriz de confusión mostró 209 verdaderos negativos, 43 verdaderos positivos, 14 falsos positivos y 16 falsos negativos. El análisis manual de 20 errores permitió identificar que las confusiones más frecuentes estaban asociadas con etiquetas discutibles, terminología técnica ambigua y artículos de predicción estadística confundidos con machine learning. Este patrón refleja una limitación propia de TF-IDF: el modelo aprende asociaciones léxicas, pero no comprende completamente la diferencia conceptual entre econometría, estadística predictiva y métodos de ML/IA.

Por tanto, se seleccionó la regresión logística como modelo final. Sin embargo, su uso debe mantenerse dentro del dominio documentado y con supervisión humana. Los resultados no deben generalizarse automáticamente a otros idiomas, tipos documentales o áreas temáticas. Antes de un posible despliegue real, sería necesario validar el modelo con nuevos datos, revisar la definición de las etiquetas y explorar representaciones capaces de capturar mejor el contexto semántico.
